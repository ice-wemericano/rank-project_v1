전체 요청 = 들어온 조회 시도 수 · 반영 = 조회수로 인정된 수 · 미반영 = 방어에 걸러진 수
분당 시도 = 최근 1분 동안의 시도 수 (작은 글씨는 직전 30분 분당 평균). 최근 1분이 10건 이상이면서 평소의 3배 이상이면 급증
사유 코드: duplicate(중복) · rate_limited(속도초과) · bot(봇) · no_proof(열람증명 없음) · proof_mismatch(다른 IP/쿠키의 증명) · bad_pow(작업증명 실패) · dwell_too_short(체류부족) · no_device/bad_device(Lv7 디바이스 증명 없음·실패)
소급 차감 (Lv6 사후 스크러빙): 인라인으로는 통과했지만, 집계를 다시 보니 분산 공격으로 판정돼 나중에 깎인 수. 실제 조회수 = 반영 − 소급차감.
scrub_ua_mono(여러 IP가 같은 UA = 프록시/봇 풀) · scrub_subnet(같은 /24·/64 대역에 IP 집중 = 데이터센터/프록시) · scrub_anomaly(Lv8: 하드 규칙을 아슬아슬하게 피했지만 집중도 이상점수 초과) · scrub_cluster(Lv10: 행동 그래프에서 한 캠페인으로 묶임) · scrub_rep(Lv10: 데이터센터/프록시 평판 대역)
Lv9 불투명 응답: 공격자에게 성공/실패를 알려주지 않음(항상 "반영됨"으로 응답). 진짜 판정은 서버·대시보드에만 남는다.
